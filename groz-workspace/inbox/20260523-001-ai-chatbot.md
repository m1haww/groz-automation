# Task Brief: AI ChatBot App

**Task ID:** 20260523-001-ai-chatbot
**Requested by:** Mihai / GROZ team
**Date:** 2026-05-23

## Brief

Vreau să creez o aplicație mobilă (iOS Swift + Flutter) cu un AI ChatBot.
Utilizatorul deschide app-ul și vede un chat interface unde poate conversa cu un AI.

## Core idea

- Ecran principal = chat screen (mesaje user + răspunsuri AI)
- Input bar cu buton send
- AI backend: Claude API (claude-haiku-4-5 pentru cost redus)
- Mesajele se păstrează în sesiune (conversație continuă)
- Design minimalist, dark mode first

## Platforms

- iOS (Swift / SwiftUI) — prioritate
- Flutter — optional, după iOS

## Constrainturile

- Fără autentificare în v1 (guest mode)
- Fără history persistent între sesiuni (v1)
- Rapid, responsive UI
- Apple guidelines compliant (nu spam reject)

Mihai — owner GROZ APPS
