# Task Brief: AI Assistant App

**Task ID:** 20260523-001-ai-chatbot
**Requested by:** Mihai / GROZ team
**Date:** 2026-05-23

## Brief

Vreau să creez o aplicație mobilă (iOS Swift + Flutter) numită **AI Assistant**.
Utilizatorul deschide app-ul și vede un chat interface unde poate conversa cu un AI.

## Core idea

- Ecran principal = chat screen (mesaje user + răspunsuri AI)
- Input bar cu buton send
- AI backend: Claude API (claude-haiku-4-5 pentru cost redus)
- Mesajele se păstrează în sesiune (conversație continuă)
- Design minimalist, dark mode first

## Color Design System (OBLIGATORIU — referință: Chat Smith app)

Culorile sunt inspirate din screenshot-ul aplicației Chat Smith:

```
Background primary:    #000000  (negru pur)
Background card:       #111111  (negru card/panel)
Background input:      #1A1A1A  (negru input field)
Accent primary:        #00C896  (verde teal — butoane, iconițe active, border input)
Accent hover/pressed:  #00A87E  (verde teal mai închis pentru pressed state)
Text primary:          #FFFFFF  (alb)
Text secondary:        #8A8A8A  (gri mediu — placeholder, subtitle)
Text on accent:        #000000  (negru pe butoane verzi)
Border subtle:         #2A2A2A  (border card-uri)
```

### Aplicare culori:
- **Chat bubble user:** background #00C896, text #000000
- **Chat bubble AI:** background #1A1A1A, text #FFFFFF, border #2A2A2A
- **Input bar:** background #1A1A1A, border #00C896 când focused
- **Send button:** #00C896 cu icon negru
- **Tab bar active:** icon #00C896
- **Tab bar inactive:** icon #8A8A8A
- **Navigation bar:** background #000000, title #FFFFFF

## Screens necesare

1. **Home/Chat screen** — lista de chats sau direct chat nou
2. **Chat screen** — conversația activă cu AI
3. **Settings screen** (minimal) — clear history, about

## Platforms

- iOS (Swift / SwiftUI) — prioritate
- Flutter — optional, după iOS

## Constrainturile

- Fără autentificare în v1 (guest mode)
- Fără history persistent între sesiuni (v1)
- Rapid, responsive UI
- Apple guidelines compliant (nu spam reject)

**AI Assistant**
- Bundle ID: `com.aiassistant.app`
- App Store name: `AI Assistant — Chat & Ask`
