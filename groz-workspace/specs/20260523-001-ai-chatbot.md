# Spec: AI ChatBot — Conversational AI cu Response Style Selector

**Task ID:** 20260523-001-ai-chatbot
**Author:** GROZ Proposer
**Date:** 2026-05-23

## Problem

Utilizatorul GROZ dorește o aplicație mobilă iOS care oferă o interfață de chat cu un AI (Claude Haiku). Aplicația trebuie să fie rapid responsivă, dark mode first, fără autentificare în v1, și să ofere o experiență de conversație continuă în cadrul sesiunii curente. Scopul: produs distinct, simplu de folosit, care trece Apple review fără probleme de tip Guideline 4.3.

## Solution

App de chat AI minimalist care folosește `claude-haiku-4-5` via Anthropic API (HTTP direct). Ecranul principal este o interfață de chat în dark mode cu streaming real-time al răspunsurilor. **Unghi unic față de chatbot-urile standard:** utilizatorul poate alege "Response Style" (Concis / Echilibrat / Creativ) din header-ul chat-ului, schimbând dinamic system prompt-ul și comportamentul AI-ului — fără a reporni conversația.

## User flow

1. App se deschide → Splash screen 1.5s → `OnboardingEntryView` router (region gate + A/B variant din Remote Config)
2. Onboarding multi-step (5 variante A–E, + Japan/Korea regional): prezintă beneficiile app-ului cu animații spring, request notification permission la ultimul step
3. Final onboarding → trigger Hard Paywall (RevenueCat, entitlement `ai_access`)
4. User se abonează sau iese din paywall → `ACChatView` (Chat Screen principal)
5. Pe Chat Screen: câmp gol cu placeholder "Ask me anything…" + Response Style Picker în navigation bar (Concis / Echilibrat / Creativ), default Echilibrat
6. User scrie mesaj → apasă Send → mesajul apare imediat (optimistic) → typing indicator (3 dots) → răspuns Claude apare token cu token (streaming via AsyncStream)
7. Conversația continuă in-session; la uciderea app-ului, history dispare complet
8. Icon settings → `ACSettingsView`: buton "Clear conversation" + info versiune

- **Claude API:**
  - Endpoint: `https://api.anthropic.com/v1/messages` cu `"stream": true`
  - Model: `claude-haiku-4-5`
  - Headers: `x-api-key`, `anthropic-version: 2023-06-01`, `content-type: application/json`
  - Streaming: Server-Sent Events (SSE) parsate via `URLSessionDataDelegate`, emise prin `AsyncStream<String>`
  - System prompt dinamic per `ACResponseStyle`:
    - **Concis:** "Respond in 1–3 sentences max. Be direct and precise."
    - **Echilibrat:** "Respond clearly and helpfully. Match the depth to the question."
    - **Creativ:** "Respond with imagination and variety. Use examples, analogies, or unexpected angles."
  - Conversation history trimisă la fiecare request (messages array cumulat în sesiune)

- **Dependencies noi:**
  - NU există SDK Swift oficial stabil pentru Anthropic → integrare via `URLSession` direct
  - Firebase Analytics, Remote Config, Messaging (SPM — identic template)
  - RevenueCat + RevenueCatUI (SPM)
  - AppTrackingTransparency, AdSupport (iOS native)

- **Data persistence:** NIMIC — `ACSessionStore` este `@StateObject` in-memory, se șterge la kill app
- **Firebase Remote Config key:** `"chat_experience_variant"` (NU `"onboarding_variant"` — previne coliziune cu alte apps GROZ)
- **RevenueCat:** entitlement `"ai_access"`, product IDs `com.groz.aichat.pro.monthly` / `com.groz.aichat.pro.yearly`
- **Bundle ID:** `com.groz.aichat`
- **Firebase project:** separat dedicat `groz-aichat` (NU shared cu alte apps)

## Acceptance criteria

- [ ] App pornește, Firebase configurat, onboarding apare cu varianta servită din Remote Config `chat_experience_variant`
- [ ] Onboarding are 5 variante A–E funcționale + Japan/Korea regional; notification permission cerută la ultimul step (NU la launch)
- [ ] Hard paywall apare după onboarding și nu se poate skip (RevenueCat entitlement `ai_access`)
- [ ] Chat screen afișează input bar, buton Send, și Response Style Picker în nav bar
- [ ] Response Style Picker schimbă efectiv system prompt-ul (testabil: "Concis" returnează răspunsuri scurte, "Creativ" returnează răspunsuri elaborate)
- [ ] Mesajul user apare imediat în UI după Send (optimistic, înainte de răspuns API)
- [ ] Typing indicator (3 dots animați) apare în timp ce Claude răspunde
- [ ] Răspunsul Claude apare în streaming token cu token — NU wait-and-dump
- [ ] Conversația se resetează la uciderea app-ului (in-memory only, verificat cu Instruments)
- [ ] Dark mode activat by default; UI respectă Safe Area pe iPhone SE, 14, 15 Pro Max
- [ ] Haptic feedback la Send (`ACHapticEngine.impact(.medium)`) și la primul token primit (`.selection`)
- [ ] Toate textele din UI au chei în `Localizable.strings` în toate cele 15 limbi GROZ
- [ ] Analytics events loggate: `ac_message_sent`, `ac_response_received`, `ac_style_changed`, `ac_chat_cleared`
- [ ] AppTrackingTransparency prompt apare (via AppDelegate)
- [ ] NU există API key hardcodat în cod (verificare pre-commit)

## GROZ rules compliance

- **Respect CODING_LAWS uniqueness:**
  - Prefix `AC` pentru toate clasele/struct-urile; naming tematic: `ACConversationOrchestrator` (nu `AppViewModel`), `ACHapticEngine` (nu `HapticManager`), `ACSubscriptionGateway` (nu `SubscriptionService`)
  - Folder structure `Features/Core/Shared/` — distinct față de `Views/ViewModels/Services/` și față de `Modules/Domain/Infrastructure/` din alte potențiale apps GROZ
  - Analytics event naming cu prefix `ac_` (`ac_message_sent`, nu `recording_started`)
  - Firebase Remote Config key: `"chat_experience_variant"` (NU `"onboarding_variant"`)
  - RevenueCat entitlement: `"ai_access"` (NU `"Main"` sau `"premium"`)
  - Bundle ID: `com.groz.aichat` (unic)
  - Feature funcțional unic: Response Style Selector (Concis/Echilibrat/Creativ) care modifică system prompt-ul — funcționalitate absentă în chatbot-urile standard

- **Respect IOS_TEMPLATE_BASE:**
  - `AIChatApp.swift` cu `@UIApplicationDelegateAdaptor`, `ACAppViewModel` ca `@StateObject` root
  - `AppDelegate` cu Firebase, FCM, ATT, RevenueCat `Purchases.configure()`, delay 2s pentru notification permission
  - Onboarding A/B (5 variante + Japan/Korea) wired la Remote Config
  - Hard paywall via `.fullScreenCover` post-onboarding
  - `GoogleService-Info.plist` din Firebase project `groz-aichat` (separat)
  - Toate 15 limbi `.lproj/` prezente
  - `codemagic.yaml` prezent

- **Respect UI_GUIDELINES:**
  - Dark mode first (background `#0D0D0D`, surface `#1A1A1A`)
  - Accent color: `#7C3AED` violet (distinct față de `#ef4444` roșu menționat ca posibil brand GROZ — Mihai confirmă)
  - Spacing grid 4/8/16/24pt
  - Border radius: bubble mesaje 16pt, buton Send full-pill (capsule), input bar 12pt
  - Touch targets minimum 44pt (iOS HIG)
  - Animații: `.interpolatingSpring(stiffness: 170, damping: 15)` pentru bubble appearance; `.easeOut(duration: 0.2)` pentru typing indicator fade
  - Iconografie: SF Symbols (`paperplane.fill`, `ellipsis.bubble`, `gear`, `xmark.circle`)
