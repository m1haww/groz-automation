# Spec: Neura — AI ChatBot App

**Task ID:** 20260523-001-ai-chatbot
**Author:** GROZ Proposer
**Date:** 2026-05-23

## Problem

Utilizatorii GROZ au nevoie de o aplicație mobilă iOS unde pot conversa natural cu un AI
prin interfață de chat. Aplicația trebuie să fie simplă, rapidă și plăcută vizual (dark mode)
pentru utilizatori care vor asistență AI ocazională fără a se înregistra sau plăti upfront.

## Solution

O aplicație iOS SwiftUI numită **Neura** — chat minimalist cu AI (Claude Haiku) care rulează
pe sesiune curentă (fără persistență). Unghiul unic: **AI Persona Selector** — utilizatorul
alege la începutul sesiunii modul AI (Asistent, Profesor, Coach, Creator), fiecare cu
personalitate și ton diferit via system prompt. Interfața folosește stil glassmorphism pentru
bubble-uri, animații de tip "thought ripple" la typing indicator, și streaming răspuns
token-cu-token.

## User flow

1. User deschide app → splash screen (0.8s) → dacă prima deschidere: Onboarding (varianta A/B din Remote Config)
2. Onboarding: 4 steps — intro Neura, demo chat (animated), persona preview, notification permission
3. Hard Paywall RevenueCat → dacă subscribed sau trial accepted → ChatView
4. ChatView: ecran gol cu empty state ("Alege cum te pot ajuta azi") + PersonaSelector sheet (bottom)
5. User selectează Persona (Asistent / Profesor / Coach / Creator) → sheet se închide
6. User tastează mesaj în InputBar → apasă Send (sau Enter)
7. Mesajul apare imediat în bubbles (user = dreapta, AI = stânga)
8. Typing indicator animat (3 puncte cu ripple) → răspuns AI apare streaming (token cu token)
9. Input blocat pe durata răspunsului AI
10. Conversația continuă în sesiune; la închiderea app-ului, istoricul se șterge

## Technical approach

- **Platform:** iOS Swift / SwiftUI — prioritate. Flutter = v2, out of scope acum.
- **Architecture:** MVVM cu `async/await` + `AsyncStream` (diferit de alte apps GROZ care folosesc Combine)
- **Naming prefix:** `Neura` — ex: `NeuraChatViewModel`, `NeuraMessage`, `NeuraPersona`, `NeuraAPIClient`
- **Folder structure:**
  ```
  Features/
    Chat/           ← ChatView, InputBarView, MessageBubbleView, TypingIndicatorView
    Persona/        ← PersonaSelectorSheet, PersonaCardView, NeuraPersona enum
  Core/
    API/            ← NeuraAPIClient.swift (Claude SSE streaming)
    Analytics/      ← ConversationTracker.swift (Firebase wrapper)
    Config/         ← NeuraRemoteConfig.swift (Firebase Remote Config)
  Shared/
    Theme/          ← NeuraPalette.swift, NeuraPalette+Dark.swift
    Extensions/     ← View+GlassCard.swift, String+Truncate.swift
    Haptics/        ← VibrationEngine.swift
  ```
- **Claude API:** `claude-haiku-4-5`, endpoint SSE streaming (`/v1/messages` cu `stream: true`)
  - Key stocat în `Info.plist` la `CLAUDE_API_KEY` (din env var la build time via Codemagic)
  - Max tokens per răspuns: 1024
  - Fiecare Persona are `system_prompt` distinct hardcodat în `NeuraPersona.swift`
- **In-session messages:** `@Published var messages: [NeuraMessage]` în `NeuraChatViewModel`
  - `NeuraMessage` = `{ id: UUID, role: .user/.assistant, content: String, timestamp: Date }`
  - La terminarea sesiunii (ScenePhase .background) → `messages.removeAll()`
- **Dependencies noi:**
  - Niciuna — Claude API prin `URLSession` nativ (SSE parsing manual)
  - Dependencies template standard: Firebase, RevenueCat (via SPM)
- **Data persistence:** Nimic (in-memory only, by design v1)
- **RevenueCat:** entitlement ID = `"neura_pro"` (unic, diferit de alte apps GROZ)
- **Firebase Remote Config key:** `"neura_onboarding_variant"` (unic)
- **Firebase Analytics events:** `"neura_session_started"`, `"neura_message_sent"`, `"neura_persona_selected"`
- **Bundle ID:** `com.groz.neura`

## UI Design

- **Stil:** Glassmorphism dark — bubble-uri cu `.ultraThinMaterial` + border `0.5pt` alb 20% opacitate
- **Background:** gradient radial `#0A0A0F` → `#12121A` (nu pur negru)
- **Bubble user:** gradient `#6366F1` → `#8B5CF6` (indigo-violet, distinct — NU roșu brand)
- **Bubble AI:** `.ultraThinMaterial` glass cu text alb
- **Accent GROZ `#ef4444`:** folosit DOAR pe Send button și Persona selector active state
- **Typography:** SF Pro Rounded (nu SF Pro standard folosit în alte apps)
  - Headlines: SF Pro Rounded Bold 20pt
  - Body chat: SF Pro Rounded Regular 16pt
  - Timestamp: SF Pro Rounded Regular 11pt, 40% opacity
- **Spacing grid:** 4/8/16/24pt (consistent cu HIG)
- **Border radius:** bubble = 18pt corner radius (asimetric: `UnevenRoundedRectangle`)
- **Animații:** `.interpolatingSpring(stiffness: 200, damping: 18)` pentru bubble appear
- **Typing indicator:** 3 cercuri cu `withAnimation(.easeInOut(duration: 0.5).repeatForever())` offset
- **Touch targets:** minimum 44pt (HIG compliant)

## Acceptance criteria

- [ ] App pornește, Firebase configurat, splash apare max 0.8s
- [ ] Onboarding apare la prima lansare (varianta servită din Remote Config `neura_onboarding_variant`)
- [ ] Notification permission cerută în ultimul step onboarding (NU la launch)
- [ ] Hard paywall RevenueCat apare după onboarding, nu se poate skip
- [ ] ChatView apare după paywall cu PersonaSelector sheet deschis automat la prima sesiune
- [ ] User poate selecta una din 4 Persona (Asistent, Profesor, Coach, Creator)
- [ ] Mesajul utilizatorului apare imediat în bubble dreapta după Send
- [ ] Răspunsul AI apare streaming (token cu token, nu deodată)
- [ ] Typing indicator animat vizibil între trimitere și primul token
- [ ] Input blocat (disabled) pe durata răspunsului AI
- [ ] La închiderea app (ScenePhase .background) conversația se șterge din memorie
- [ ] Eroare API afișată ca bubble roșu cu mesaj generic (nu crash)
- [ ] Dark mode exclusiv (nu light mode fallback în v1)
- [ ] Toate 15 limbile `.lproj/` prezente (chei localizare pentru UI static)
- [ ] AppTrackingTransparency prompt apare
- [ ] Build compilează fără warning pe Xcode latest

## Open questions

1. **Claude API Key management:** Key se pune în Codemagic env vars? Sau există un proxy backend GROZ prin care trec request-urile? (Dacă proxy → endpoint diferit, autentificare diferită)
2. **Trial / Paywall:** RevenueCat default UI sau custom? Brief nu specifică. Recomandăm default UI pentru v1 (mai rapid).
3. **Onboarding illustrations:** Custom illustrations sau SF Symbols extended? Brief spune "minimalist" — sugerăm SF Symbols + lottie animații simple pentru rapiditate.
4. **Rate limiting:** Dacă user trimite 100 mesaje/sesiune → costuri mari. Avem un cap per sesiune (ex. 50 mesaje)? Sau lăsăm RevenueCat paywall să filtreze?
5. **Streaming SSE:** Claude API v1 streaming via `URLSession.bytes(from:)` în Swift — confirmat că funcționează pe iOS 16+? Da, dar necesită target deployment iOS 16.0 minimum.
